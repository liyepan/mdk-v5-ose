feat: 补上构建引擎、工具链配置、Error List、命令行构建

把 Qt 版那套核心能力搬过来了：

Core
- Toolchain：按目录探测 armcc/armclang（AC5/AC6）、armasm/armlink/armar/fromelf，
  猜 Keil 安装路径，跑 --vsn/--version 取版本号
- Settings：JSON 配置（工具链路径、并行数、最近工程、窗口大小），
  路径按 配置目录 -> 用户目录 -> 程序目录 依次退，免得 HOME 为空时往当前目录写
- Diagnostic：armcc / gcc / armlink 三种输出格式的解析（文件、行、列、错误码、消息）
- BuildEngine：和 uVision 一样按阶段跑
    [BeforeCompile] -> [编译/汇编 并行] -> [BeforeMake] -> [链接或 armar] -> [fromelf] -> [AfterMake]
  增量是三合一：源文件 mtime + 自己扫 #include 的本地头文件 + 编译参数指纹（.mdk-ose/<target>.sig）
  按 IROM1/IRAM1 生成 scatter，useUlib 时自动补 __MICROLIB，
  --map --list=<file> 出 map 并从 Grand Totals 取 Program Size

UI
- 工具 -> 配置编译器：选目录后自动识别 AC5/AC6，存进配置
- F7 编译、重新编译、清理、停止；编译期间按钮状态跟着变
- Build Output 追加输出（uVision 格式）、Error List 双击跳到出错行
- 状态栏显示 Program Size、编译器、光标位置
- 最近打开的工程菜单、启动自动打开上次工程、窗口大小记忆
- 多 Target 切换

CLI
- --build <uvprojx> [--toolchain <dir>] [--target N] [--rebuild] [-j N]
  输出和 uVision 一致，退出码 0/1，方便进 CI
- WinExe 在 cmd 里跑时挂到父控制台，否则看不到输出

验证：用假 armcc/armlink 脚本做了端到端测试 —— 并行编译、汇编、增量跳过、
scatter 生成、Program Size 解析、错误时跳过链接且退出码为 1，都符合预期。
